# grill-with-docs

Рабочий процесс команды для спорных решений; это не внешний навык. Инициатор формулирует решение, затронутые REQ-ID и обратимый вариант для демо. Рецензент читает М-01, C4, ADR-007 и соответствующие строки реестра, выписывает утверждения с источниками и отделяет их от предположений.

Для каждого утверждения разобрать: какую атаку оно останавливает, какой законный сценарий ломает, кому принадлежит состояние, где точка упорядочения, что произойдёт при timeout/повторе/позднем событии/неопределённом COMMIT, каким тестом это доказать. Привести контрпример и измеримый критерий принятия. Для подтверждения спросить о восстановлении и доступности.

Команда/ментор фиксирует accepted/deferred/rejected, ответственного и дату в ADR или OpenSpec; до этого решение помечается допущением. Затем обновляются контракт, тест и трассировка в PR. Владельцы и календарь ревью пока открыты. Внешний openspec CLI закреплён 1.11.0; сгенерированные им Codex skills зависят от этого CLI. Этот срез добавляет только два собственных навыка и OpenSpec init. Появившиеся во время работы сторонние навыки/skills-lock.json команды сохранены без изменений и не используются для выполнения демо; их версии и зависимости нужно проверить отдельно перед подключением к CI/процессу.
