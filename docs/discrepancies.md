# Источники, расхождения и вопросы

Прочитаны исходные М-01 DOCX, ADR-007 DOCX (Accepted для учебного проекта), C4_1..4 PNG и «Ресёрч Антифрод-систем (2).xlsx», лист «ФТНФТ NEW». Файла буквально `ресерч.xlsx` нет; предоставленная книга используется как реестр. Текстовые извлечения в sources сохраняют исходные ID; DOCX/PNG/XLSX остаются источником при расхождении извлечения.
